# 开发方案

## 2026-11-25 完整体验迭代

用户确认的首要问题是怪物威胁过低、移动缺少距离与操作实感、整备及商店缺少正式游戏界面的组织。优先完成盐港单图的局内体验与跨局循环。参考三角洲行动的仓库和大厅组织、ARC Raiders 的 PvE 与局势变化、ZERO Sievert 的单人任务和经济成长。持续采用纯程序生成资产。

| 阶段 | 需求及交付 | 验收与现状 |
| --- | --- | --- |
| 1 · 操作与 PvE | 有加减速的奔跑、长滑铲、保留动量的跳跃、连贯翻越、镜头/手部/脚步反馈、清楚的怪物预警和有压力的追击；保留视锥、遮挡、听觉、脱战规则。可调视野与动态效果。之后按路线收益和消耗试玩负重、体力及更多行为差异。 | 首轮已实现。[移动与 PvE 验收](qa/PHASE_ONE.md)。继续人工试玩校准操作和难度。 |
| 2 · 大厅与整备 | 全屏大厅，顶部大厅/仓库/商人/任务/基地导航，右上货币及设置，右下选图与出击；左侧可旋转人物和装备/随身袋/背包，右侧占格仓库，支持拖拽、旋转、快移、拆分、检视、筛选、自动整理；独立商店及地图详情，网页启动与出击分阶段加载动画。 | 本轮已实现界面及整备操作，详见[第二阶段验收](qa/PHASE_TWO.md)。等级、任务奖励和基地建设随第 4、5 阶段接入；仓库容量运营规则随第 3 阶段完善。 |
| 3 · 经济、装备与结算 | 自带物资的消耗、损失和归还；商品购买/出售、材料兑换、维护与容量扩展；独立结算显示带出和损失、净收益及历史出击。新增头部、能量护甲、两主武器/副武器/近战分组与实模图标。 | 已实现五阶能量护甲、可充能与维护、工地安全帽和自动前向照明矿灯安全帽、120 格可扩建仓库、兑换及跨局结算记录。详见[第三阶段验收](qa/PHASE_THREE.md)。两个主武器槽仍预留，待后续装备内容扩充。 |
| 3.5 · 盐港地图重构 | A 总体分区、地标、出生/撤离与空间规划；B 可探索码头、开口集装箱和停靠邮轮；C 差异化建筑、内外景、探索与地区资源；D 统一地图 UI、拖动缩放、楼层、标记及全图验收。 | 用户确认在第 4、5 阶段之前优先完成。按[地图质量需求](design/MAP_REBUILD.md)分步交付；3.5A [总体蓝图 V1](design/MAP_REBUILD_35A.md)完成并待审阅，尚未改动运行时地图。 |
| 4 · 任务与局内变化 | 港务调查、回收记录/样本、恢复设施、交付、权限与商人信誉；按地区区分物资用途、特殊容器和稀有物资；敌人残骸可搜、检视与品质反馈；随机遭遇、锁房、储藏点、局势与撤离事件；有不同表现和反制窗口的虚构敌人变体。 | 基线已有种子掉落、逐件搜索、区域、三种撤离、局内提示及 35 种插画物品；缺少持久的委托、物品多用途和显著局势变化。不同种子应产生不同路线决策。 |
| 5 · 基地与成长 | 工作台、医疗站、储物室、情报中心、研究台使用现有材料提供升级、制作和解锁；长期任务、等级/信誉、不同天气、日夜及特殊遭遇。 | 首版可用菜单表现基地；目标是连续出击积累有用途的资源。 |
| 6 · 内容与成品体验 | 扩充装备、敌人、地图与主题探索；环境声音、设施动画、拾取反馈、HUD 整理、教程、战绩与设置完善；先将首图打磨到可重复游玩再考虑第二张图。 | 维持键鼠、桌面浏览器、离线单人 PvE。各地图均须完整验证出生、搜索、遭遇、撤离和经济回流。 |

阶段验收先以功能回归和生产构建为基线，再以真实浏览器记录场景与控制流程，人工试玩用于校准操作感及平衡。已有系统沿用当前实现，后续完善安排在对应阶段；详细玩法参考[盐港机制实施方案](design/SALTPORT_RAID_PLAN.md)。

3.5 是第 4、5 阶段的前置质量门槛：暂缓正式持久委托、随机局势和基地成长的实现，待地图分区、地标及资源锚点稳定后再布置。

## 历史里程碑

2026-11-13 的[下一阶段清单](demo/NEXT_PASS.md)记录先前版本的待优化项及验收。采用纯程序内容与单会话串行制作；下表记录早期里程碑，M1 的并行安排不再作为默认调度。包体、生成耗时和内存专项验证暂缓。

首个版本聚焦 [废弃装卸区与地下实验室](demo/FIRST_MAP.md)。每局从预设地面出生点随机进入，带小刀和少弹手枪。玩家决定搜地面、下实验室，或者选择一条当局可用的撤离路线。桌面浏览器、键鼠、离线单人作为初版验证环境。

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| M0 运行基线 | 新的 Vite、TypeScript 和 Three.js 项目，实机画布、输入、移动、基础帧时间 | 本地启动、构建与 Chrome 鼠标锁定通过。资产测试件能挂载并受控播放 |
| M1 四线并行 | 运行与出击、首图、战斗与敌人、角色与武器表现 | 按首图规格的共享类型和入口对接。各线保留独立验证证据 |
| M2 初版整局 | 3 个随机候选出生点、地下实验室、两类敌人、物资和 3 个撤离点 | 至少实测一局地面撤离和一局实验室撤离。刷点、刀枪、条件锁定、死亡和入库均可复验 |
| M3 观感与平衡 | 优化手臂、枪械、怪物和地上地下的环境对比，调试少弹和风险收益 | 审查实际 ADS、命中、换弹和敌人预警画面。以固定路线和种子记录帧时间、弹药、搜刮收益 |
| M4 地区扩展 | 按地图配置扩展地区与敌人组合 | 新地区有明确的威胁、资源与撤离条件 |

首图通过后再评估联机、大地图、装备交易和长期成长。
