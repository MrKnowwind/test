# 盐港隔离区 · 试玩与验收

基线为 GitHub 上的 `7fded13`。三个提交按背包与撤离、角色移动、地区与实走修复的顺序排列。完整交付包中的 `Saltport-FieldBuild.html` 可用桌面 Chrome 或 Edge 直接打开，点击「开始出击」锁定鼠标。用 Esc 暂停，M 查看战术地图。有 WebGL 2 的浏览器可离线游玩。正式存档保存在当前浏览器，新下载的本地文件与线上站点各自保存进度。

## 手动复测

1. **袋位与物品守恒**。按 Tab 看无包时的三块随身袋。Esc 开启创造模式，在脚边生成登山包，E 打开并装备。换长条包，对照顶袋、长主仓和两个上袋。点击备弹堆，用滑条或加减号拆组。开箱后 Shift 加左键快移，拖到最右侧松手，再按 E 拾回。可用练习局自由观察地图。
2. **公路和维修口**。西南公路（−151，145）入圈后走出，再入圈等满 5 秒。中央仓储值班室（−9，13）搜索文件盒拿维修卡。到东北维修口（189，−90），倒计时中丢卡应取消，捡回重新等满 5 秒。正式局可在结算页核对带出库存。
3. **研究区**。从洗消门廊下坡进入 B1，经过样本柜到配电柜（16，−168.7）。对柜按 E，站在楼上的同一平面坐标会错过货梯。再呼叫一次，进入 B1 货梯地圈（15.4，−155）等到零。配电柜至圈中心按折线路径实测步行 3.03 秒、冲刺 2.02 秒，12 秒包括转身、辨路和躲避的余量。
4. **动作**。进中央仓库，面朝滚筒台（−11.1，−0.55）按 X 蹲穿，台下再次按 X，走出后才会起身。回到主通道，按住 Shift + W 冲刺后按 X 滑铲，收蹲后再按 X 起身。去南侧救护站东边的高台阶，面朝近边按 Space 起跳，在空中再按一次 Space，观察探手、接触、撑起和持枪恢复。C 保留静走。
5. **辨路**。西侧沿水岸货轨向东出坡，穿过仓储装卸月台，再经南侧主路折向厂区管汇。研究区从双列喷头进入地下，沿管线观察样本柜、配电柜与梯门。仓库南侧短通道回接外围主路时视线被货垛分割，熟悉出入口前较易走向尽头；辨路难度仍需首次游玩的玩家确认。

## 证据与复现

- 画面对比使用基线和本轮各自的生产构建。种子 42、Balanced、同一视角，896×504，覆盖码头、仓库外立面、仓内滚筒台、处理厂、研究入口、公路撤离。背包另测 1280×720 和 1920×1080。录屏来自游戏渲染帧，按每四个模拟步采一帧，首尾停留用于看清姿态。
- 使用 Chromium、WebGL 2 和 SwiftShader。路线和动作以 60 Hz 仿真推进，取证帧完整绘制。背包用正常浏览器动画循环操作。照片、录像和仿真路线时间均不能代表玩家显卡的 FPS。
- 从源码运行 `npm ci`、`npm test`、`npm run build -- --base=./`。若本机已有 Playwright Chromium，可运行 `node tests/field-pass-browser.mjs dist test-results/field-pass`；使用自定浏览器时设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。日常试玩用 `npm run dev`，可在网址后加 `?seed=42`。分批结果为第一批 36 项、第二批 34 项相关检查通过，最终全套 76/76。Vite 提示主 JS 大于 500 kB，生产构建成功。
- 设计参考取自普通与条件撤离的区分、第一人称动作的手部接触，以及以大形和用途识别地图分区。本轮场景、模型、音效和动画由工程生成。[三角洲官方地图](https://www.playdeltaforce.com/act/mapswiki/) · [GDC 第一人称动画](https://gdcvault.com/play/1024319/Animation-Bootcamp-The-First-Person) · [Riot 环境美术](https://playvalorant.com/en-us/news/dev/the-art-of-valorant-map-environments/)
- 待评估的设计包括出击带入经济、委托、货梯警报与长期成长。先看正式局地下收益、首次辨路时间、大包实际装载率和遭遇时的 12 秒余量，再决定是否调参。
