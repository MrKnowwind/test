# 盐港 · 搜刮与场景精修 A–C 验收

2026-11-28。以 `a21bbc7` 为实现基线，[A–F 开发计划](../design/SCENE_LOOT_POLISH.md)已独立提交。仅完成 A–C；D–F 的贴图、灯光、三个美术样板和全图推广不在本轮改动范围。

## A · 物品模型、白边与 HUD

- `presentation/lootModels.ts` 对现有 98 个物品 ID 建立显式模型配方，图标里的主色、剪影和部件作为造型参考。7 个背包、5 阶护甲、两顶头盔、充能单元以及现有装备外观复用对应模型。所有模型底面归零，复用几何和材质但实例变换相互独立；散落物、玩家丢弃及创造生成统一由 `addSearchContainers` 创建。
- 通过带深度测试的屏幕像素扩边材质绘制实际物体轮廓，普通 1.3 CSS px、当前目标 2.3 CSS px；选取 10 米内最近最多 14 个可交互目标，已取走/清空及离开范围后收回轮廓。该方法进入世界渲染，不依赖高画质专属的后处理。未使用穿墙色或全屏扫描。
- 右下角常驻当前弹量与实际弹匣容量；空手、近战、治疗隐藏，低弹量着色。仍可使用检查弹药按键短时强调面板，不展示备弹。库存与整备原有规则不变。

## B · 容器与散落资源

- 203 个原有容器保留 ID、内容池和容量；11 类模型分别采用医疗/冷藏、仪器、档案/抽屉、立柜、周转笼、货运箱和工具箱等结构；桌面与落地使用不同尺度，街屋朝向来自实际房间墙面，其他容器按邻近的站立空间和无遮挡方向选朝向。搜索后指示灯变化，清空后取消轮廓。
- 新增 30 个独立室外支持点（码头与露天甲板、中央物流、工业、科研、住宅与交通站、北部高地）。以实际托盘、推车、检修台支撑，绕开道路/步道、原搜刮点、障碍和坡面，不改变出生及撤离。原 12 处候选加新点共 42 处。256 个种子随机散落物均值约 25.55（原 6.83），单局 17–34 个，另保留旧的固定物资。
- 全部 203 个容器实际模型包围盒与建筑/家具碰撞体复核：无三个轴均超过 15 毫米的重叠。修正邮轮三间客房的容器支撑高度和样品柜底部贴地。

## C · 结构与外围

- 检查全部建筑的轴向立面、顶面下表面与饰边：`tests/scene-geometry-audit.mjs` 对差异色面按 2.5 毫米平面距、正面积相交及可见射线判断。首轮发现 206 个代表性候选机位；修复中央旧仓柱墙/门框、科研楼雨棚、档案中心屋檐、潮沟端头、集装箱内壁/门板/地板和编号贴片、研究区梁柱、北部挡墙、联排住宅屋顶/座椅、街屋转角、架空导轨、货仓夹层及补给台阶接缝。最终扫描 122,969 个候选三角面，按当前门槛无残余暴露重叠。该扫描不等于任意曲面、动态模型或材质的所有穿模都已排除。
- 北、东、南侧新建与真实陆地轮廓相接的多环背景地形、直道路延伸、不同高度的城区厂房及植被；西海域维持邮轮和货船，远岸建筑由实体岸线支撑。不可进入背景不写入通行碰撞列表；主地图边界和外海登船保持原样。
