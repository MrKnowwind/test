# 盐港 · 3.5C 第二轮

基线 `069423a`。本轮把八个部署点与对侧常规撤离接入战局，施工中央冷链仓、东部备件配电仓和北部检查口前场。

| 场景 | 实装 |
| --- | --- |
| C2 冷链仓 | 18×24 m，地坪世界 Y=+3.6m，两端各有 22m 直坡，纵坡约 16.4%。两个装卸口之间是贯通车道，两侧分为签收、低温药品和冷机维护空间。外墙保温板、缓冲门框、双层机房顶和外置冷机用程序几何制作。 |
| E3 备件配电仓 | 26×30 m，地坪世界 Y=0m，比冷链仓低 3.6m。高低跨屋面、试验台、配电柜、备件架和变压器组围绕双向维修通道布置。 |
| 北部检查口 | 常驻位置 (26, −212)，地坪世界 Y=+1.8m，从北部东西直路接入，11m 直坡约 16.4%。 |
| 南部公路出口 | 保留 `highway` ID，迁至 (26, 171)，由南侧主路接入。两侧出口都用通行设施、地面色标和撤离圈识别。 |

两个仓库替换原重复货棚，合计六个带真实支撑和可达视线的搜索点。冷链坡面与检查口坡面共用地坪、道路和碰撞数据。大厅预览、大地图及小地图更新了新建筑、坡面和常规出口。地图中的名称只用于界面定位。

## 部署与撤离

- 四个北部候选共享南部公路出口，四个南部候选共享北部检查口。每局随机选一个候选，随后固定本局开放的常规点。进入开放撤离圈后计时 5 秒，离圈取消。进入同侧圈显示“本局未开放”。
- N-A 从规划预留点调整到西北台地道路，避开检查厅室内；其余七处沿用规划水平锚点。各点统一发放所选整备，场上旧南侧基础小包仍是一件。
- 维修通道继续校验随身维修卡。B1 货梯继续校验配电、所在层和离站窗口。

## 复现

- `npm test` 106 项通过，覆盖八条路线、同侧封锁、两个条件撤离、六个搜索点，以及角色控制器在坡顶接缝的双向通过。
- `npm run build -- --base=./` 通过，生成 Pages 生产包。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/district-rebuild-browser.mjs` 使用生产包验证出生至对侧撤离、普通局中同侧撤离的 HUD 和战术图提示、冷链搜索及配电仓贯通。长路线用关闭飞行的练习模式，W/Shift 负责位移。报告和场景图写入 `test-results/district-rebuild/`。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/harbor-browser.mjs` 回归两座连桥、船上三层和西北直坡。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/field-pass-browser.mjs dist test-results/district-conditions exits,service` 回归离圈取消、货梯楼层与重呼、维修卡丢弃拾回及结算。整备至出击、撤离至出售另由 `tests/outpost-browser.mjs` 回放。

后续 3.5C 继续迁移科研园和 B1 的相对高程，补齐工业、居民和物流其余用地并重构陆地轮廓。完整 22.5m 高差仍是蓝图目标。3.5D 的地图交互和配发套装选择待 3.5C 后进入。
