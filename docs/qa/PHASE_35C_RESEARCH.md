# 盐港 · 3.5C 第三轮 · 科研园与 B1 高程

基线 `ace9a50`。本轮施工 N3 科研主楼与 B1，共用高程基准，现场定位使用建筑形体、材质和界面提示。

| 地点 | 实装 |
| --- | --- |
| 科研园平台 | 40×50m，海面以上 12m，对应世界 Y=9.9m。南侧 54m 直路接至平台，纵坡约 18.3%。北侧 18m 步梯连接北部东西道路。 |
| 科研主楼 | 20×20m，南北都有出入口。1F 有登记台和样品接收台，2F 有档案柜和观测终端，二层地坪高出首层 3.35m。三处搜索点及其家具共用实体支撑。 |
| B1 实验室 | 原水平包络与 17m 入口坡道保留。实验室地坪升至世界 Y=4.5m，仍比园区地坪低 5.4m。配电柜、低温保存柜、货梯、敌人和灯具同时迁移。 |

平台基础围合 B1，顶板与路面在坡口留出通道。HUD、渲染、环境音、敌人寻路与听觉、小地图均使用科研园的局部空间数据判定 B1。站在货梯正上方可以错过一次离站并重新呼叫。两组出生点及常规撤离仍按上一轮规则决定可用性。

## 验收入口

- `npm test` 共 107 项检查，覆盖八条对侧撤离路线、科研园南北连接、主楼楼梯、B1 坡口的实体与渲染净空，以及不同楼层的货梯判定。
- `npm run build -- --base=./` 构建 Pages 生产包。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/field-pass-browser.mjs dist test-results/research-pass research,exits,service` 走南坡、主楼两层、北侧步梯和 B1 坡道，搜索二层终端实物，操作配电柜并步行至货梯撤离。独立回放楼上错过货梯、B1 重新呼叫及维修卡获取、丢弃和拾回。路线使用关闭飞行的练习模式，转向使用固定机位，W/Shift 产生位移。报告和截图在 `test-results/research-pass/`。

后续 3.5C 继续施工居民区、科研园其余用地及各区地形连接。完整陆地轮廓和 22.5m 地表高差仍按蓝图推进。
