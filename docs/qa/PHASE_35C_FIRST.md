# 盐港 · 扩船及 3.5C 首轮

2026-11-26，基线 `8a604b9`。本轮消化用户对原 3.5B 的反馈，进入 C 的地形和独立公共/住宅建筑施工。并非完整 C 竣工。

## 用户反馈落实

- 移除所有用于显示建筑、地区、室内及去向名称的实体板，包括船名、门口名称、旧商铺广告牌、楼层名称、服务和撤离标牌等。保留无文字的结构/色带、实际设备屏幕与货箱编号；出口条件、互动文本、地图和 HUD 仍提供游戏信息。不留下原名牌底板。旧商铺暂按功能命名，仅保留一处独立药局名称，余下建筑形体在 C 持续替换。
- W1 船体由 89×21m 扩为约 167×44m（视觉外沿含救生艇 X −232～−186，Z −112～55）；陆地边界 X=−172 不变。船体宽度和长度均明显增长，保留两座 21.4m 登船桥，船舱、上甲板和顶层甲板的世界 Y 分别为 0.7、4.1、7.65m（相对海面 2.8、6.2、9.75m）。两座船舱至上甲板楼梯及一座顶层楼梯真实可步行，非展示用楼层；封闭驾驶桥不计入探索面积。出海支撑仍仅由船面与连桥提供。
- 新增西侧八个房间（配餐、餐厅、两种客房、影音厅、洗衣、船员和物料）、前厅休息区及船尾办公室/住宿，上甲板增加阅览、咖啡、多功能厅和活动区，顶层观景区。客房总数五种，船上新增 16 个固定搜索点，船内总数 25（整个码头 34）。从船内陈设、色带及舱窗识别空间，未增加真实航行或新撤离点。

## 验收与复现

- `node docs/design/map-rebuild/blueprint.mjs --render`：更新 W1 三层船体包络，原陆地尺度、20 条直线道路连接、26 地块和八出生/四出口规划检查通过。
- `npm test`：原有回归和新增 6 项范围测试。针对真实碰撞检测新增船翼、上下层房间、双船舱楼梯和顶层往返；北侧地面高程、道路双向通行、两座公共建筑的搜刮、观测站及三户住宅二层往返；新增容器实际存在并具有实体支撑。
- `npm run build -- --base=./`：生产构建。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/harbor-browser.mjs`：在生产构建中使用真实游戏输入通过连桥、两座船舱楼梯、顶层甲板楼梯及北侧直坡；固定 QA 机位检查船体外观、船舱/甲板、住宅、北部地形与战术图。截图和报告输出 `test-results/harbor/`（不提交生成产物）。

尚需用户自由试玩校准整体视觉、游玩路线及普通硬件的帧表现。下一轮 C 将继续中央物流、工业和科研建筑/台地迁移以及出生撤离分组；3.5D 处理地图拖动缩放、楼层细分和配发选择 UI。
