## 测试与复现

- `node docs/design/map-rebuild/blueprint.mjs --render`：验证道路直线段、连接、坡度、建筑尺度与外海船体位置。
- `npm test`：包含新增六项码头测试，覆盖落水区域无支撑、两座连桥、两层船舶及往返、四种开放货箱、九个船内搜索点、港务建筑与调度室二层的可达性及搜索。
- `npm run build -- --base=./`：生产构建。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/harbor-browser.mjs`：实际 Chromium 输入登船、上楼和通过另一桥返回；固定机位抽查外观、舱内、甲板、候船厅、集装箱及局内地图。证据输出在 `test-results/harbor/`（不提交运行产物）。

## 后续验收边界

本轮重构港口切片，尚未将 3.5A 规划的 22.5m 高差、非规则陆地轮廓、全部直线道路网和南北出撤规则全部替换至运行时；这些属于 3.5C。港区资源先复用已有物品及搜索机制，待第 4 阶段加入正式委托、区域稀有度、随局事件和额外遭遇。3.5D 再增量实现地图拖动缩放、全图楼层/出口 UI 与配发套装选择和格子来源描边。仍需用户自由试玩审视场景品质和实际硬件性能。
