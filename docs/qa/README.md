# 验收与证据

## 先验收的路径

| 路径 | 实机或自动验收 |
| --- | --- |
| 输入与性能 | 点击进入、失焦和重新进入；固定分辨率记录硬件、画质、测试场景和帧时间 |
| 瞄准与攻击 | 同一机位记录腰射、举枪、射击、命中。校验机瞄对中、遮挡、空仓和中断换弹 |
| 生化遭遇 | 从同一存档和种子观察敌人预警、攻击机会、受击和脱战；核对伤害结果 |
| 出生与地图 | 固定种子覆盖三个合法出生点，逐点验证地面路线。走坡道进出地下实验室，检查地上地下碰撞与射线 |
| 搜刮到撤离 | 测试常开公路、维修卡通道和通电货梯。验证离区取消、成功入库、重启持久化、重复结算以及死亡和放弃 |
| 画面与资产 | 验收固定机位和战斗实拍中的手臂、武器、敌人。记录轮廓、贴图、遮挡、光照和破绽 |
| 地区配置 | 用已知种子复现地面感染体、实验室安保机和研究样本位置。验证机械敌人只从实验室候选点出现 |

新作的构建、自动化和性能证据在实现阶段逐项生成。初始性能目标由 M0 的实际硬件和测试场景确定。旧项目提供 [截图与采样](../../references/saltline-lite/qa/metrics.json) 和 [浏览器 QA 脚本](../../references/saltline-lite/scripts/browser-qa.mjs) 作为方法参考。

每次验收记录基线或提交、运行方式、地图和种子、画质与设备、预期、实际、证据路径。截图说明机位和操作状态。性能报告注明采样范围和重复次数。失败记录能复现的最短步骤，修改后用同一条件复验。
