# 盐港 · 3.5C 第四轮 · 南部生活区

基线 `c50d1d7`。本轮实施 S1、S4、S6，三个台地都接通 Z=95 与 Z=155 的东西干道，两条干道中心线保持直线和原高程。

| 地块 | 本轮实装 | 高程与连接 |
| --- | --- | --- |
| S1 港务家属区 | 三户两层联排整体抬升，原有区别化内景与六个搜索点一同迁移。补上前廊、公用后院、座椅和种植箱。 | 世界 Y=3.9m，北入口为 23m 直坡，南入口为步梯。 |
| S4 社区救护与活动中心 | 原两栋重复街屋替换为两翼公共建筑。救护室有病床和用品柜，公共活动翼有接待、活动座椅和器材储物。两翼各有广场入口，内部连通。 | 世界 Y=3.6m，18m 北坡与 10m 南步梯连接抬升广场。 |
| S6 交通站与餐饮广场 | 原两栋重复街屋替换为双向候车厅、调度台、行李柜、独立餐饮间和室外桌椅。 | 世界 Y=3.0m，南北各有直坡，可从 S-C 出生点步行接入。 |

S4、S6 合计新增六处有实际支撑的搜索点，并各放置一处区内遭遇。新建筑与场景道具均由程序生成。大厅预览、大地图与小地图显示台地和建筑轮廓，HUD 沿实际入口和平台显示区域名称。四栋旧街屋退场后，其他街屋的房间与物资 ID 保持稳定。

## 验收

- `npm test` 共 108 项，覆盖南区六段坡道或步梯双向通行、联排住宅上下楼、新场景六处搜索点和八条出生至对侧撤离路线。
- `npm run build -- --base=./` 构建 Pages 生产包。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/field-pass-browser.mjs dist test-results/south-pass south` 回放 S-C 到候车厅、餐饮间、社区救护室及住宅二层。练习模式关闭飞行，实际位移由 W/Shift 产生。另检查南侧出生时南出口提示关闭，以及北侧出生时从南干道进入撤离圈结算。报告和截图输出到 `test-results/south-pass/`。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/harbor-browser.mjs` 回归邮轮、登船桥、西北台地与移高后的住宅视角。
