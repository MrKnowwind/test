# 第二阶段 · 大厅、仓库与加载过渡

2026-11-25，基线 `6f58dc7`。本轮实现用户确认的全屏布局，并改善网页进入与出击等待期间的视觉反馈。

## 功能

- 顶部大厅、仓库、商人、任务、基地。右上券余额和设置，右下选择地图与出击。大厅和仓库展示可拖动、方向键旋转的程序生成全身角色。唯一地图盐港显示实际道路与建筑概览、范围、区域、撤离信息。
- 左侧装备、随身袋和背包，右侧 10 列占格仓库。右侧格子取自既有库存账本，支持拖拽移动、旋转、拆分、筛选、检视、自动整理；配置装备及物资可拖拽和 Shift 快移，带入量预留在显示层，出击前仍重新校验库存和空间。装入可支持的占格物资，包括材料。搬动和拆分后的配置随实际入场初始化重放，退回可按目标格摆放。
- 商人提供独立商品卡片、分类、购买与回收两页，沿用现行价格与交易。商人形象、地图、图标、角色和动画均由程序生成。
- 任务页提供三条现有撤离相关简报，基地页提供储物室及补给入口。持久化委托、等级、基地升级、仓库容量经济仍按后续阶段计划制作。
- 加载条显示实际阶段和百分比，持续扫描环、光带与脉冲提供等待反馈，到达首帧后淡入。系统减少动态效果时停用循环动画和淡入。场景生成按地区、街屋批次、几何合批和实体批次让出浏览器执行时间；第一次出击复用启动时已经生成的场景，后续出击按新种子重新生成。加载期间不执行战局模拟。

## 验收

`npm test`，覆盖已有地图、移动、交互、战斗和库存回归；新增仓库布局、占格整备、库存守恒、无效布局扣除失败、旧档重排。

`npm run build -- --base=./`。

启动 `npm run preview -- --port 4281` 并执行 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=<Chromium> node tests/outpost-browser.mjs`。种子 42；正常动画，1280×720 与 768×620 两档界面。检查启动进度、选择地图及人物旋转、购买、格子旋转和拆分、拖拽带入与归仓、自动整理、首次出击及第二次重建场景的进度、真实出击格位、设置、搜刮、滑铲、撤离与出售；报告与界面截图在 `test-results/outpost/`。

本轮全套 88 项测试及生产构建通过。软件 Chromium 浏览器回放记录启动、首次出击和重建出击分别约 35、8、35 个不同进度值，到达 100% 后进入对应画面；截图审查大厅、仓库、商人、选图和加载界面。首次出击使用预载地图，第二次出击确实进入场景重新生成步骤。装备拖放位置在真实局内验证，结算后库存继续守恒。

待日常硬件人工使用确认大厅、仓库舒适度及加载体感。当前不进行包体、资源生成耗时及内存专项。
