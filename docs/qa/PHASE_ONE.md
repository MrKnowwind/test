# 第一阶段 · 移动与 PvE 首轮调整

2026-11-25，基线 `1cfba3f`。现有盐港地图、出击经济和携带规则继续使用。目标是让玩家能够感知真实的虚拟移动速度、连续操作反馈与敌人压力。

水平速度经过加速和刹停过渡。滑铲由实际奔跑速度触发，可小幅转向，碰墙或离地结束；立身须有头部净空。跳跃在空中保留速度，允许有限转向，二次 Space 仍按实际台沿检测攀爬。松键、打开背包及暂停不会积存移动指令。摄像机根据位移节奏起伏、滑铲倾斜、落地缓冲，动态效果设置可调至 0%，垂直视野 55° 至 80°，持久化到原设置档案。手部随实际速度、空中状态及落地同步，程序音效覆盖起跳、滑铲和落地。

感染者根据实际速度过渡步态。追击起始有空间化提示音，攻击仍有可见预警与遮挡判定。沿用地图绕行节点，若当前路径中间受阻则重试。现有两类敌人继续使用原生命和伤害设定。

## 复现方式

- `npm test`，覆盖加速与刹停、平地滑铲、起跳动量、禁用镜头动态、设置读写、怪物预警与视线、绕障，以及原有经济与地图回归。
- `npm run build -- --base=./`。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=<Chromium> node tests/field-pass-browser.mjs dist test-results/phase-one feel,controls,routes,exits,service`。种子 42，均衡画质，60 Hz 固定步长，896×504。移动专项在创造练习中验证碰撞，追击及预警专项使用正式出击；货梯时间窗使用创造练习隔离 PvE。截图文件名为 `feel-slide.jpg`、`feel-slide-jump.jpg`、`feel-chase.jpg`、`feel-warning.jpg`、`lift-countdown.jpg`。
- `npm run preview -- --port 4281` 后，运行 `node tests/outpost-browser.mjs`，验证整备、背包、选项持久化及结算交易。

浏览器首轮测得冲刺 7.50 m/s、冲刺视野 68.65°（过渡中）、滑铲 6.20 m、滑铲起跳 6.76 m；厂区感染者在 45 个模拟帧内移动 3.94 m，到达近距后进入预警。原地等待货梯的普通出击回放出现死亡结算，说明当前地下等待存在实际风险。下一轮需用自然路线评估完整战局的失血、消耗和撤离成功率。

## 本轮验证结果

- 全套自动测试 86/86 通过，生产构建通过。
- 浏览器完成移动专项、正式局带卡撤离（搜刮、丢弃取消、拾回、带出）、练习局货梯条件与时间窗，以及滑铲期间动作互斥、暂停中断与创造飞行。整备专项完成购买、仓库领用、局内交互、滑铲跳、键位和视野设置保存、正式撤离与出售。整备脚本报告为 `test-results/outpost/report.json`。
- 浏览器四条长路线（南侧、西侧、东侧与 B1 地下）通过。另用真实地图碰撞与角色控制器、60 Hz 固定步长独立复测，模拟移动时间为南侧 20.1 秒、东侧 96.6 秒、西侧 70.0 秒、B1 12.7 秒，不计搜索、战斗和停留。

后续校准：不同设备上的惯性、镜头动态舒适度与动作手感，地下风险和敌人数量；更全面的跨楼层寻路、敌人变体、体力负重仍在[完整体验迭代路线](../ROADMAP.md)内。
