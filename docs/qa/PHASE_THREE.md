# 第三阶段：装备、经济与结算

基于第二阶段 `f5903e8`，2026-11-25。

## 装备与界面

- 大厅仓库左侧为人物、头部、能量护甲、背包、两主武器、副武器、近战、随身袋和背包格，右侧为仓库。窄高度时左侧可独立滚动。局内装备栏与其对应；1/2 主武器目前未配备，3 为原手枪、4 为原近战。手枪与近战图标直接渲染已有模型；新增防具及充能单元图标来自同一程序模型，不引入外部贴图。
- 头部设备只有工地安全帽及矿灯安全帽。矿灯随头部位置和视线方向提供实时前方照明，卸下即熄灭；普通安全帽仅基础头部装备。两者可在商人及相应容器获得，战局带回后保留。
- 防具采用以下初始参数：

| 护甲 | 护盾上限 | 基准价值（券） |
| --- | ---: | ---: |
| 白 | 25 | 210 |
| 绿 | 50 | 360 |
| 蓝 | 75 | 650 |
| 紫 | 100 | 1100 |
| 红 | 125 | 1850 |

护盾优先吸收局内虚构伤害，余量不足时扣除生命。充能单元占 1 格、最多 4 件堆叠，1.6 秒恢复 25 护盾，受击中断不消耗。装备电量存入独立实例，撤离与换装不重置；商人可付费充满。装备可从仓库或局内容器进入对应槽位/携行格，空间不足的换装失败并保持物品。品质对应 HUD 色彩与 25 点分段。

## 经济与出击

- 初始仓库 10×12，扩建 +40 格，首次 350 券，之后每级增加 150，最多 600 格。购买及兑换需要仓库能容纳结果；撤离、旧档溢出不吞物品，仍可出售、整理或扩建。容量计入未实际出击的整备物品。
- 材料兑换：铜线圈与端子排兑换 3 个护盾充能单元；工业零件与密封圈套件兑换白阶护甲。护甲按电量折价回收、维护充满。交易保留五分钟动态报价，跨标签写入使用已有锁。
- 独立结算包含带出、损失/消耗、带回估值、领用估值及估算净收益（非即时到账券）。可堆叠物品按返还数量估算；装备按独立实例。基地展示最近 30 局；练习不计收益，生成物品不入仓。
