# 项目事实与术语

## 当前美术基线

2026-11-20 起，地面港区采用明亮的科幻赛璐璐风格，地下研究区采用冷色导光和分层舱壁。出击队员、第一人称武器、两类敌人、物资插画及背包界面共用赛璐璐色阶与港务识别色。下文的写实美术参考属于旧版；旧版完整工程位于分支 `archive/realistic-port-2026-11-20`。本轮实机记录见 [当前状态](memory/STATUS.md)。

## 已确定

- 项目方向为废土风 PvE 搜打撤。地图和地区决定可出现的敌人类型，可包含生化怪物和叛乱智械。
- 用户最新以Saltline原作公开镜像的模型、道具与场景效果为参考；旧Saltline Lite是本地历史复刻，不能冒充原作精度。人物、手部、物品和空间设计仍被用户明确指出粗糙。新项目要实现可用的第一人称瞄准与攻击。
- 每局从多个预设出生位置随机选一个。同一张地图有多个撤离点，部分撤离需要达成条件。
- 初始装备为小刀和少量弹药的手枪。初版聚焦第一张地图，主要敌人为生化怪。地下实验室是高风险、高收益区，也会刷少量机械怪。
- 1/2 为两个空主武器槽，当前不制作或掉落步枪、霰弹枪。3 为手枪，4 为近战。
- 第三阶段新增头部设备（工地安全帽、带前向照明的矿灯安全帽）、白/绿/蓝/紫/红五阶能量护甲、充能单元。护甲优先承受虚构敌人的伤害，剩余电量随物品实例保存。具体装备和经济规则见[第三阶段](qa/PHASE_THREE.md)。
- 背包采用占格空间管理，可旋转、移动、使用或丢弃物品；容器需要搜索，撤离后的战利品可变卖为本地货币。
- 主界面提供全屏大厅、占格仓库、商人、行动简报、据点、选图以及出击界面。启动资金、市场报价、仓库装备风险以及移动和 HUD 规则见 [整备、交易与战局界面](decisions/0002-outpost.md)。当前整备操作及加载验收见 [第二阶段](qa/PHASE_TWO.md)。
- 2026-11-25 用户确认优先改善怪物威胁、移动操作实感及正式游戏界面，并同意按六阶段迭代。当前执行 [完整体验迭代路线](ROADMAP.md)，首图重点为移动、PvE、经济循环与长期目标。
- 2026-11-26 用户要求在第四、五阶段前先解决地图完成度问题。增设 3.5 阶段，重构盐港功能分区、建筑和内景、可探索码头与邮轮、随出生分组开放的常规撤离及地图 UI。需求以[地图质量重构](design/MAP_REBUILD.md)为准，3.5A 总体方案先供用户审阅；未通过的规划不视为已上线。
- 3.5A 用户确认：400×400m 是陆地参考范围，邮轮凸出到西侧外海；地图采用起伏地形及不规则轮廓，主道路水平保持直线、禁止连续扭折。详见[立体地图 V2](design/MAP_REBUILD_35A.md)。仓库的基础配发按钮改为打开选择套装界面，首期仅一个方案；配发物采用特殊格描边而非左上文字，待后续 [UI 增量](design/ISSUED_LOADOUT_UI.md) 实现。
- 3.5B 试玩后用户追加：全部实体建筑、区域、室内名称板取消，不保留空白名牌；保留装备/设备功能界面、货箱识别编码与地图/HUD 定位。邮轮扩大为 167×44m 船体、三层可探索，优先以空间、材质及陈设区分地标。3.5C 首轮开始真实高程和住宅/公共建筑切片，进度见[阶段验收](qa/PHASE_35C_FIRST.md)。
- 2026-11-13 曾将外观列为最高优先级，用户提供本地 `1.mp4` 为质感参考；视频本身不能验证资产制作来源。用户已解除禁止联网搜索的要求，运行资产仍由本地工程提供。
- 后续采用 [额度控制规则](WORK_BUDGET.md)：默认主会话单独执行，按任务读取上下文、制作资产和验证，减少重复并行、出图及日志。用户尚未认可当前角色与环境质量；手枪可暂作为保留基线。
- 游戏内容制作采用纯程序生成。模型、材质、场景、图标、音效和动画均由代码创造，不使用 AI 图片或现成内容资产；通用引擎/代码库与技术参考可用。P0 已迁出历史 AI 贴图的运行加载与打包引用，图源保留为非运行历史参考；迁移证据见 [程序材质记录](art/PROCEDURAL_PASS.md)，持续约束见 [额度控制规则](WORK_BUDGET.md)。
- 此前曾按 [下一阶段执行清单](demo/NEXT_PASS.md) 推进纯程序资源、地图/远景/物件密度、逐件搜刮与角色动作。包体、生成耗时和内存专项验证仍暂缓；常规构建、功能与画面检查保留。
- 初版规则见 [首图制作规格](demo/FIRST_MAP.md)，当前地图已扩展为 400×400 m，操作以源码、[地区增量](demo/DISTRICT_PASS.md) 和 [逐件搜索](demo/SEARCH_PASS.md) 为准；[第二版](demo/V2.md)、[旧地图布局](demo/V2_MAP.md) 仅保留历史基线。当前美术证据见 [程序内容增量](art/PROCEDURAL_PASS.md)，迁移前记录见 [历史外观修订](art/VISUAL_REFINEMENT.md)。

## 共用术语

| 术语 | 含义 |
| --- | --- |
| 出击 | 从进入地图到撤离、死亡或放弃的一次游戏会话 |
| 局内背包 | 当前出击拾取的物品，终局由结算流程处理 |
| 仓库 | 结算后可跨出击保留的本地物品记录 |
| 撤离区 | 满足条件时可启动撤离倒计时的区域 |
| ADS | 举枪瞄准。机瞄对齐相机中心，并有明确的进入和退出状态 |
| 切片 | 一段可独立试玩和验证的完整流程 |
| 地区 | 配置可出现的敌人类型、掉落和地形特征的内容单位 |
