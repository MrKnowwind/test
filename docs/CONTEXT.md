# 项目事实与术语

## 已确定

- 项目方向为废土风 PvE 搜打撤。地图和地区决定可出现的敌人类型，可包含生化怪物和叛乱智械。
- 用户最新以Saltline原作公开镜像的模型、道具与场景效果为参考；旧Saltline Lite是本地历史复刻，不能冒充原作精度。人物、手部、物品和空间设计仍被用户明确指出粗糙。新项目要实现可用的第一人称瞄准与攻击。
- 每局从多个预设出生位置随机选一个。同一张地图有多个撤离点，部分撤离需要达成条件。
- 初始装备为小刀和少量弹药的手枪。初版聚焦第一张地图，主要敌人为生化怪。地下实验室是高风险、高收益区，也会刷少量机械怪。
- 1/2 为两个空主武器槽，当前不制作或掉落步枪、霰弹枪。3 为手枪，4 为近战。
- 背包采用占格空间管理，可旋转、移动、使用或丢弃物品；容器需要搜索，撤离后的战利品可变卖为本地货币。
- 外观是当前最高优先级。用户于 2026-11-13 提供本地 `1.mp4` 为质感参考；视频本身不能验证资产制作来源。用户已解除禁止联网搜索的要求，运行资产仍由本地工程提供。
- 后续采用 [额度控制规则](WORK_BUDGET.md)：默认主会话单独执行，按任务读取上下文、制作资产和验证，减少重复并行、出图及日志。用户尚未认可当前角色与环境质量；手枪可暂作为保留基线。
- 游戏内容制作采用纯程序生成。模型、材质、场景、图标、音效和动画均由代码创造，不使用 AI 图片或现成内容资产；通用引擎/代码库与技术参考可用。P0 已迁出历史 AI 贴图的运行加载与打包引用，图源保留为非运行历史参考；迁移证据见 [程序材质记录](art/PROCEDURAL_PASS.md)，持续约束见 [额度控制规则](WORK_BUDGET.md)。
- 用户要求另开一个会话继续制作，按 [下一阶段执行清单](demo/NEXT_PASS.md) 推进纯程序资源、地图/远景/物件密度、逐件搜刮与角色动作。包体、生成耗时和内存专项验证暂缓；常规构建、功能与画面检查保留。
- 初版规则见 [首图制作规格](demo/FIRST_MAP.md)，当前地图已扩展为 400×400 m，操作以源码、[地区增量](demo/DISTRICT_PASS.md) 和 [逐件搜索](demo/SEARCH_PASS.md) 为准；[第二版](demo/V2.md)、[旧地图布局](demo/V2_MAP.md) 仅保留历史基线。当前美术证据见 [程序内容增量](art/PROCEDURAL_PASS.md)，迁移前记录见 [历史外观修订](art/VISUAL_REFINEMENT.md)。

## 共用术语

| 术语 | 含义 |
| --- | --- |
| 出击 | 从进入地图到撤离、死亡或放弃的一次游戏会话 |
| 局内背包 | 当前出击拾取的物品，终局由结算流程处理 |
| 仓库 | 结算后可跨出击保留的本地物品记录 |
| 撤离区 | 满足条件时可启动撤离倒计时的区域 |
| ADS | 举枪瞄准。机瞄对齐相机中心，并有明确的进入和退出状态 |
| 切片 | 一段可独立试玩和验证的完整流程 |
| 地区 | 配置可出现的敌人类型、掉落和地形特征的内容单位 |
