# 玩法与关卡设计

本页由玩法设计角色维护。这里记录玩家能观察到的规则、关卡路径和遭遇设计。实现方案、资产规格、调参值各由对应职责维护。

当前优先事项：[3.5 盐港地图质量重构](MAP_REBUILD.md)；[3.5A 立体地形蓝图 V2](MAP_REBUILD_35A.md)已按反馈修订，待用户审阅。[配发套装及描边](ISSUED_LOADOUT_UI.md)为后续 UI 增量。下文首片规格为历史基线，新的地图方案经审阅后按 3.5B–D 实施。

## 已定方向

- 做废土风 PvE 搜打撤。不同地图和地区出现不同敌人，题材包括生化怪物和叛乱智械。
- 旧港区 Demo 的环境精度、雨夜空间和工业材质可作为参考。新项目要补齐人物与武器的近景表现，并实现真正可玩的瞄准、射击和命中反馈。

以下内容是首个可玩切片的提案。建议沿用第一人称，以桌面浏览器、键鼠、离线单人模式验证玩法。最终平台、是否联机和长期成长仍待决定。

## 首个可玩切片

**废弃装卸区与地下实验室**。地面三个固定候选点随机选一个。玩家携带小刀与少弹手枪，在生化怪为主的地面区选择搜刮、绕行或前往实验室。地下的狭窄通道混有少量机械安保机，研究样本提供更高收益。具体候选点、撤离条件和首版接口见 [首图制作规格](../demo/FIRST_MAP.md)。

| 阶段 | 玩家行动 | 游戏反馈 |
| --- | --- | --- |
| 进入 | 从预设点随机出生，携带小刀、手枪和少量弹药 | 每个出生位都能辨识地标并整理操作 |
| 搜刮 | 接近容器，查看内容并拾取 | 搜刮物进入局内携带栏，满载时显示原因，玩家可替换物品 |
| 遭遇 | 借掩体脱离、用刀近战或举枪射击 | 生化怪前摇与机械锁定能区分，命中、空仓和受伤均有反馈 |
| 撤离 | 到达有标识的撤离区并启动倒计时 | 进入、计时与中断可读，离开区域时取消，可再次启动 |
| 结算 | 查看带回物品或死亡损失，开始下一局 | 成功时把携带战利品写入仓库一次。失败或主动放弃时清除当局战利品，保留既有仓库。下一局可重新领取起始装备 |

首片只验证起始配装、携带物和仓库结果查看。商店、任务链、复杂装备装配、付费经济及联机留在后续范围。

### 关卡导向与风险

- **出生区**各有掩体，用应急灯和引导标识建立装卸棚、公路与实验室的方位。
- **主通道**经装卸棚中心，距离短，有高价值容器和敌人巡逻。堆箱提供能中断视线的掩体，近距离接敌时留有退路。
- **绕行路线**经过设备和围栏，收益较低，可保存弹药与生命。每个出生点都有地面路线抵达常开公路出口。
- **地下实验室**让玩家用狭窄视线和有限弹药换取更高价值物资。安保机先预警再攻击，实墙能切断锁定。货梯供电前仍可按原路返回地面。
- **撤离区**用独立照明、编号和边界区分。公路常开，维修通道检查维修卡，实验室货梯检查配电。条件未满足时说明原因。

### 瞄准与交战

- 手枪右键按住进入瞄准，松开恢复腰射。屏幕中心、后照门和前准星对齐。左键攻击，刀的距离和挥击时间可读。手枪换弹并有空仓反馈。
- 障碍先挡住射线时，目标不受伤。尤其要检查贴墙或探角时的镜头与枪口偏移。开火、命中、受伤分别有声音和画面反馈，玩家能判断失误原因。
- 生化怪能巡逻、察觉、追击和前摇攻击，机械安保机在地下以锁定预警和射击施压。二者都能被掩体切断视线。
- 死亡与撤离完成发生在同一更新时，首片提议死亡优先。退出或重开一场未结算的行动按放弃处理。结果页和持久化实现遵循同一规则。

## 地区扩展

以下是候选地区。首片敌人可读性和搜打撤循环通过后，再增加地区与敌人组合。

| 地区 | 常见敌人 | 玩家可识别信号与应对 |
| --- | --- | --- |
| 废弃装卸区 | 生化近战感染体 | 脚步、嘶吼、突进前摇。用箱体遮挡，观察巡逻间隙，保留撤退距离 |
| 封闭净化设施 | 潜伏或喷吐型生化怪 | 拖行声、腐蚀痕迹、蓄力姿态。避免盲角，识别危险通道与替代路线 |
| 废弃自动化中转站 | 叛乱巡检机、安保机 | 扫描灯、伺服声、锁定警报。避开扫描扇区，利用实墙切断视线 |

每个地区定义可出现敌人、巡逻或驻守地点、战利品分布、通行与撤离条件。需要设计不同的敌人组合时，先说明该组合增加了什么玩家决策，再提交美术与平衡需求。

## 玩法验收

1. 用不同种子检查三个候选出生点。每个点都能在不进入实验室的情况下抵达公路出口。
2. 验证刀的命中范围、手枪 ADS、射击、换弹和空仓反馈。墙后与探角分别检查攻击遮挡。
3. 地面可绕行或交战。进入实验室时能辨认安保机预警并拿到高价值样本。
4. 检查维修卡和配电前后各自的撤离状态。带物资撤离与仓库一致。离开撤离区取消倒计时，重新进入后可再次启动。
5. 死亡或放弃后检查当局物品损失与原有仓库保留。刷新结果页或重复确认不重复增加物品，重开后仍可领取起始装备。

## 交接边界

| 职责 | 交接内容 |
| --- | --- |
| 美术与动画 | 为武器提供腰射、瞄准、开火和换弹的可读姿态；为敌人提供察觉、攻击前摇、命中和倒地的可辨信号；为关卡提供可识别的掩体、搜刮和撤离标记 |
| 数值 | 按敌人威胁与线路风险设计弹药、伤害、携带容量、战利品和计时初值。基于试玩数据调整，记录变更依据 |
| 工程与测试 | 用同一局内状态管理携带物、敌人、撤离和结算。提供固定布置的成功、失败与绕行场景，支持复现命中、遮挡和结算 |

后续需要确认最终平台与联机范围、目标局长、撤离条件是否随地图变化、长期仓库与进场损失规则，以及哪些敌人机制应成为第二张地图的主题。
