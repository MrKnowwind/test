# 配发套装选择与物品来源标识（待实现）

2026-11-26 用户追加，纳入 3.5D UI 整合，可在地图制作过程中独立小步交付。当前仅记需求，不更改正式游戏。

## 配发选择界面

- 仓库「人物与装备」区现有直接执行整备重置的 `#reset-loadout` / 「基础配发」，改为入口按钮「配发选择」。点击只打开专用的配发套装选择界面，不立即重置整备。
- 新界面使用正式大厅一致的样式，显示套装列表、所选套装的装备槽及携行预览、套装说明和确认/返回；只启用一个明确的「基础配发」方案，不展示可领取但未实现的虚假套装。套装数据组织为可扩展的列表，后续增加方案不重做页面结构。
- 首套方案沿用已上线 `defaultLoadout`：原配发副武器、近战及配发弹药，不擅自增加新免费装备。显示实际已装填及备弹状态，使用原有实模图标。
- 确认后调用现有整备变更、校验与返还逻辑。已有自带整备被替换时提示其将退回仓库；取消/关闭不产生变化。重复选择、库存不足、刷新和切换套装不应复制物品或改变付费归属。
- 首次打开、已选择、确认失败、返回仓库及小屏或低窗口高度等状态均完整设计。保留键盘操作、焦点管理和现有整备拖放。

## 配发格子特殊描边

- 取消占据物品图标左上角的 `.issued-mark` 文字，包括「配发」「混合」「自带」。配发来源以独立边框/角标形状表现：优先采用低饱和青蓝双层描边或短方角边，保持图标与数量可读。常规自带格不额外占用文字位置。
- 与现有品质底色和品质提示分离。全配发格用配发专属轮廓；混合堆叠采用可辨识的分段描边或双区间轮廓，检视/无障碍说明展示配发、自带具体数量。不能只靠颜色辨认，也不覆盖数量、护盾电量或拖拽反馈。
- 大厅装备槽、随身格、背包，以及局内装备/背包保持一致；仓库中不得出现配发专属描边的可销售库存。图标不可被额外标签遮挡。
- 依据现有 `issued` 数量与总数量判断标记（全配发、混合、自带三态），不得仅按物品类型或装备来源字符串推断。合堆、拆分、消耗、拖放、换装和结果结算继续使用现有来源守恒规则。

## 验收

1. 点击「配发选择」进入套装页，只有一个可用方案；确认前原整备不变化，点击返回无副作用。
2. 确认后正确显示套装及配发特殊描边，已预约的自带货物退回，套装不能重复刷取入库；失败时保持旧整备。
3. 全配发、混合、自带格在普通/稀有品质、拖放选中、旋转、不同分辨率和数量显示下可区分，图标左上角无覆盖文字，检视能读取来源数量。
4. 实测合堆/拆分、出击、消耗、撤离、再次配置的来源数量与库存守恒，保留现有练习和正式局的结算语义。
