# 第二版战斗与敌人交接

本版保留出生时的 6 发装填 + 6 发备弹手枪与小刀。主武器键 1/2 预留为空槽，传入 rifle 或 shotgun 不改变当前武器、弹量或换弹状态。数字键到武器 ID 的映射由输入模块负责。

| 武器 | 攻击与装填 |
| --- | --- |
| 手枪 | 每次按下扳机一发，最短间隔 0.4 秒，换弹 1.6 秒，ADS 可持续按住 |
| 小刀 | 挥击 0.65 秒，在动作进度 0.36 结算接触，范围 1.55 m |

手枪从相机方向选择目标，并检查相机与枪口间、枪口到目标间的遮挡。手枪和刀消费扳机按下沿。切到小刀会中断手枪换弹，弹药在完整装填结束时转移。医疗和弹药补给对死亡玩家无效。

感染体追击增加近距离实体探测和固定侧向绕障，在低矮箱体前能继续接近目标。丢失视线时只搜索最后看到的位置，5 秒后恢复巡逻。机械安保机保留完整锁定预警，实墙打断锁定，重新露面重新计时。当前绕障为碰撞查询驱动的局部转向，楼层和实体通行性由地图查询负责。

## 验证

执行 node --test tests/combat.test.mjs，15 项通过。覆盖初始配装、空主槽、手枪节奏、刀接触时机、近墙射击、感染体绕低箱、丢失视线、机械锁定打断、死亡与补给。固定脚本在 30 FPS 与 60 FPS 下的手枪伤害和弹量一致。

本线修改文件为 src/combat/createCombat.ts、src/enemies/createEnemy.ts、tests/combat.test.mjs 和本页。地图和表现由并行制作线交付，数字键、枪口挂点与实机动画在集成后联验。背包、搜刮和卖物由主会话维护。
