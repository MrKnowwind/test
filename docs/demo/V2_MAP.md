## 美术实现与检查

环境采用可复用的程序化 PBR 材质，同一高度场生成法线，配套颜色、粗糙度、锈蚀和雨痕遮罩。重点钢板与地表纹理为 512。箱壁采用梯形折板真实几何，箱门锁杆、铰链、角件和边梁保留实体。静态物件按 20 m 空间块和材质合并，保留各拾取物独立命名节点。

实拍复查后调整了地面与天花的法线强度、颗粒明暗和物理 UV 尺度，降低锈蚀遮罩强度。仓库加入窗带、门框、檐口和基座。出生点货车包含驾驶室、车窗、车轮、侧镜、底盘和货架，实验室加入分段面板、门洞收边、隔离柱与电脑台。局部积水使用环境 PBR 高光。

当前场景的证据保存在 test-results/world-v2/。spawn.png、warehouse.png 和 lab.png 是本轮第一次审查，带 -revised 的图片为修改后。主会话负责完整人物、战斗、背包和最终渲染的联合验收。
