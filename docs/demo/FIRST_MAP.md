# 初版 Demo · 废弃装卸区

每次出击从预设地面出生点随机选择一个，出生朝向和附近地标固定。玩家携带小刀、手枪和少量弹药。地面以生化怪为主，有可绕行的通路和普通补给。地下实验室有更紧的视线、更密的遭遇、高价值研究样本和少量故障安保机。实验室入口可自由进入，风险和撤离条件在进入前能看见线索。

| 内容 | 初版落地值 |
| --- | --- |
| 出生点 | 南侧卸货口、仓库外巷、废车棚。等权选一点，固定种子可复现。出生在安全掩体后，三个点都能经地面到达公路出口 |
| 公路出口 | 常开。留一条能避开实验室的地面路线 |
| 维修通道 | 需要携带维修卡。卡放在地面值班室，撤离不额外扣卡 |
| 实验室货梯 | 需要开启实验室配电柜。通电状态仅作用于本次出击 |
| 撤离交互 | 在区域内按 E 启动，暂定连续停留 5 秒。离开取消。终局只结算一次，同一更新的死亡优先 |
| 初始配装 | 小刀与手枪。手枪 6 发装填、6 发备弹。1/2 为空主武器槽、3 手枪、4 近战；左键攻击，右键按住举枪，R 换弹 |
| 敌人 | 地上与地下出现近战感染体。实验室候选点中按种子放置少量机械安保机。首片用 1 台验证锁定预警和掩体对抗 |
| 战利品 | 地面有弹药、医疗和普通物资，实验室至少能拿到一个高价值研究样本 |

探索和撤离均不要求击杀。三个出口各有标识，条件未满足时显示原因。死亡或放弃时丢失局内拾取，仓库保留已保存的结果。启动新一局重新发放基础装备。

后续修订增加 6×5 占格背包、容器搜索和撤离后的变卖。Tab 打开背包，R 旋转选中物品，拖动调整位置，双击可用补给。当前地区范围、坐标和通路见 [第二版地图](V2_MAP.md)，主武器资产不在本轮制作范围内。

## 并行边界与接口

共享类型见 [demo.ts](../../src/contracts/demo.ts)。坐标为米，Y 向上，位置表示角色脚底，yaw 为弧度，正前方为 -Z。帧时间用秒。公共类型由集成线维护。各线先验证自己的入口，按如下导出接入。

| 会话 | 写入范围 | 导出或交付 |
| --- | --- | --- |
| 运行与出击集成 | 根项目配置、入口、`src/app/`、`src/player/`、`src/raid/`、`src/ui/`、`tests/raid*` 和 `tests/browser*` | Vite、输入、世界装配、出生抽取、条件与倒计时、拾取、结算、仓库和整局 QA。拥有整合后的可试玩入口 |
| 首图与实验室 | `src/world/`、`tests/world*` | `src/world/firstMap.ts` 的 `createFirstMap(seed: number): FirstMap & { scene: THREE.Group }`。连通地上地下，坐标表与实际碰撞一致 |
| 战斗与 AI | `src/combat/`、`src/enemies/`、`tests/combat*` | `src/combat/createCombat.ts` 的 `createCombat(world: WorldQueries, enemies: readonly EnemySpawn[]): Combat`。实现小刀、手枪、补给、伤害、敌人和命中遮挡 |
| 角色与武器美术 | `src/presentation/`、`assets/`、`tests/art*` | `src/presentation/viewmodel.ts` 的 `createViewmodel()` 返回 `{ group, muzzle, update(dt, weapon, moving) }`。同目录 `enemyVisuals.ts` 的 `createEnemyVisual(kind)` 返回 `{ group, update(dt, enemy) }`。武器挂到玩家相机，敌人根节点脚底在原点，位置和朝向由集成线设置 |

走坡道时 `moveGrounded` 负责落点高度和实体碰撞。碰撞和射线区分地上、地下。战斗从相机中心取得目标，再用枪口到目标的射线排除近处掩体。怪物追击和攻击受实体与视线约束。美术消费可观察状态，移动和攻击的权威在运行和战斗模块。

出生抽取与敌人布置使用传入种子，可独立复现。地图交付配电柜、物资、撤离条件与实际位置。集成线维护拾取、背包、当局条件和结算保存。最终用真实浏览器试玩和生产构建验收整局。
