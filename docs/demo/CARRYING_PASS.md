按 Tab 查看装备。三块随身袋共 14 格，开局 15 发备弹占一格，手枪弹匣另有 8 发。选中物品再点目标格，R 转向，也可拖放。双击已揭示条目可快取。可在搜索中途离开，返回后继续。将枪移出装备栏后检查快捷键，放回可恢复枪和剩余弹量。

撤离后，仓库显示本局实际带出物。选一件变卖，核对库存减少和券数增加；免费配发枪、刀及剩余配发备弹不计销售库存。再开一局拿到物资后放弃，核对损失清单及上一局库存。

## 验证入口

`npm test` 检查种子、格子边界、守恒、搜索、死亡、入仓重试和已有地图碰撞。专项为 `node --test tests/carrying.test.mjs`。生产构建为 `npm run build -- --base=./`。本地可用 `npm run dev`，打开终端显示的网址并附同一 seed。

待对照试玩的参数包括首次找到背包的时间、外围和地下的每分钟收益、实战时大包的收益与风险。请按固定种子记录第一次想撤离的地点、当时的 HP 和剩余备弹。

## 守卫与搜刮压力

转运仓南北通道有巡逻感染者。分别在同一种子按住 C 静走、正常走路、按 Shift 向前冲刺，观察守卫何时转向、调查或追击。实枪射击会产生更远的声音，隔墙衰减。安保机看见人才开始锁定；用实体墙打断，再探头需重新锁定。贴墙时观察 P8 压低并提示挡枪，开包时仍能听见方向预警、看见受击方位。

种子 2 的南侧救护站储备箱有急救包和基础治疗针剂。受伤后用背包的「使用」，或长按 5 并用鼠标／方向键选药，松开确认，再按 H 或短按 5 施用。急救包需连续 2.5 秒，完成回 40 HP；受击中断后药包仍在。针剂每秒扣一格耐久、回 10 HP，满血提前停止。再按 H、切枪或开包可取消。剩余两格的针剂撤离后可卖 60 券。
