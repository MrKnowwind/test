# 第二版角色与武器表现

> 本文记录 AI 贴图接入之前的第二版基线。2026-11-13 之后以 [外观修订](../art/VISUAL_REFINEMENT.md)、[第一人称](../art/FP_REFINEMENT.md) 与 [感染体](../art/INFECTED_REFINEMENT.md) 为当前实现；下列 512 程序纹理描述不代表最新生产包。

本版第一人称资产为手枪和小刀。角色与武器素材由本地代码生成，源文件位于 `src/presentation/`。

## 实现

- 手枪套筒改为有斜切顶面的轮廓，保留分开的套筒、枪管、抛壳口、照门、前准星和可移动弹匣。材质区分磷化钢、磨损金属、聚合物和橡胶。侧面增加本地生成的制造标识。
- 手套指段沿连续弯曲曲面收束，增加指背接缝和保护片。袖子沿前臂收束，衣褶实际改变轮廓，接缝和腕带随腕部位置一同拟合。
- 512 贴图生成器统一生成相互对应的色彩、粗糙度和由高度场导出的法线。金属有局部擦伤、油迹和细划痕，织物与皮革分别采用织纹、磨损和皮面细褶。
- 切换武器时下放后回位，移动与转向使用克制惯性。手枪 ADS 的前准星、后照门与相机中心重合。换弹时手与弹匣共同移动。小刀接触动作对齐攻击进度 0.36，再收回恢复。
- 感染体的工装与肢体采用蒙皮连续曲面，脸部使用收窄下颌、眉骨和不对称皮肤变形。局部残破呼吸器与工装缝线强调工业人员来源。机械安保机增加装甲分片、线束、卡箍和紧固件，锁定时展开护板并改变传感器状态。

## 验证

`node --test tests/art.test.mjs` 的五项行为测试通过，覆盖 ADS 投影、枪口火光、换弹接触及复位、感染体攻击预警与倒地、机械锁定状态。TypeScript 全项目检查通过。

`node tests/art-browser.mjs test-results/v2-art` 在 Chrome 157 / RX 5700 XT 下生成 13 张独立资产实拍，无页面、控制台和资源错误。已查看并修正首轮图中的指部反面、过亮手套分片及球状病变体积。截图包含手枪腰射、ADS、开火、换弹，小刀待机和攻击，以及敌人动作。

集成场景另拍摄了 `test-results/v2-art/14-main-hip.jpg` 和 `15-main-ads.jpg`。正常入口的鼠标锁定和右键举枪通过，页面错误为零。集成图的地图与灯光取自同一工作区的当时版本。

角色当前的面部、衣物和材质仍属于程序化原型精度，后续需要更精细的角色雕塑、UV 与烘焙来接近目标角色资产。整局性能和最终画面的验收由集成会话记录。
