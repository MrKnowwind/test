# 工程设计

当前已有可运行本地 Demo。实现及验收以 [STATUS](../memory/STATUS.md)、[地区增量](../demo/DISTRICT_PASS.md)、[逐件搜索](../demo/SEARCH_PASS.md) 为准；下文保留初期模块职责方案。选择记录见 [决策索引](../decisions/README.md)。

| 模块 | 拥有的状态与职责 | 依赖或产出 |
| --- | --- | --- |
| 应用与输入 | 启动、页面生命周期、鼠标锁定、输入映射 | 把输入意图交给玩家模块；失焦清除持续按键 |
| 玩家与战斗 | 移动、碰撞、武器状态、ADS、射击、弹药、伤害 | 世界查询结果；发出命中、弹量和状态事件 |
| 敌人与地图 | 敌人感知、移动、攻击和地区生成；地面、遮挡与撤离区域 | 用地区配置生成遭遇；提供射线与可通行性查询 |
| 出击与存档 | 出击阶段、局内物品、结算、跨局仓库 | 用唯一出击 ID 提交；读写带版本的记录 |
| 表现 | 场景、动画、UI、声音、照明 | 根据模拟状态或事件显示结果；可以在不改伤害与掉落的情况下独立迭代 |
| 内容配置 | 武器、敌人、掉落、地图和资源索引 | 校验单位、ID、引用和范围；测试可注入固定种子 |

等 M0 确认技术路线后，按切片建立实际需要的目录。

| 拟建目录 | 放置内容 |
| --- | --- |
| `src/app/`、`src/player/` | 启动、输入、第一人称控制 |
| `src/combat/`、`src/enemies/` | 武器、伤害、敌人行为 |
| `src/world/`、`src/raid/` | 地图查询、出击、背包、撤离与结算 |
| `src/presentation/` | 场景渲染、动画、UI 与声音 |
| `content/` | 地图、敌人、武器、物品和掉落配置 |
| `assets/`、`tests/` | 源资产与导出物，以及独立的行为与浏览器验收 |

首次实现就用正常游戏入口验收。目录和模块从实际调用关系生长，共用类型由集成负责人维护。

## 首批契约

- **命中**由战斗模块计算。先从相机中心取意图目标，再检查枪口到该点的通路。若枪口受阻，以首个障碍为准。画面火光、后坐和命中标记消费统一结果。
- **动画**与美术共同定义手部持枪点、机瞄和枪口。武器状态决定能否开火、扣弹和换弹，动画事件定位表现时机。暂停和掉帧时要检查行为和表现是否仍能对齐。
- **结算**把出击状态推进到撤离成功、死亡或放弃。成功保存局内战利品时，同时记录对应的出击 ID（`runId`）；同一 ID 重复提交只产生一次入库效果。若选浏览器存档，在 M2 评估单事务和异常恢复。
- **地区**用稳定 ID 连接地图、敌人类型、掉落池和资产。武器和敌人参数从一处配置读取。测试可固定地图、随机种子、配置版本与输入序列。

旧 Demo 可参照 [第一人称控制](../../references/saltline-lite/src/player/FirstPersonController.ts)、[交互遮挡](../../references/saltline-lite/src/gameplay/interactions.ts) 和 [浏览器 QA](../../references/saltline-lite/scripts/browser-qa.mjs)。复用前按新游戏的角色、碰撞和战斗条件独立验证。
