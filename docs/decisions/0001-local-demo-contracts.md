# 0001 本地 Demo 契约

日期：2026-11-13。状态：用户已定规则已落实，本地技术方案采用中；首发平台和最终美术满意度仍待确认。

## 当前决定

- 初始只有手枪 6+6 和小刀。1/2 是两个空主武器槽，3 手枪、4 近战。不因保留 WeaponId 类型而生成步枪或霰弹枪资产与拾取。
- 每局从三个固定候选点随机选择，首图有公路、维修卡和实验室通电三种撤离。条件必须在倒计时中持续满足，死亡优先于同帧撤离。
- 背包用 6×5 格点坐标和物品方向管理空间。容器有独立 6×4 网格，出击创建时按种子确定内容；未知占格逐件揭示，关闭保留进度，未揭示不可转移。每件转移和背包放置原子校验，失败保留原件；补给由背包主动使用。
- 带出物资按 runId 去重入仓。变卖记录和货币在同一条市场账户记录保存，保留旧版逐局仓库格式。模型/存档/公共类型变化由集成会话协调。
- 坐标为米、Y 向上，角色根节点表示脚底。相机向前 -Z，yaw 为弧度，dt 为秒。第一人称保留枪口、机瞄、弹匣、持握挂点；敌人根位置由运行时控制，表现消费行动状态。
- 当前使用本地 Three.js/Vite 单人浏览器版本。2026-11-13 用户修订：整个游戏的内容改为纯程序生成，禁止 AI 图像和现成内容资产；P0 已迁出历史 AI 贴图运行依赖，图源仅留作历史参考。执行以 [额度与制作规则](../WORK_BUDGET.md) 和 [下一阶段清单](../demo/NEXT_PASS.md) 为准。

## 依据与边界

规则来自用户当前会话，规格及历史聊天不覆盖用户后续修正。实现入口在 `src/contracts/demo.ts`、`src/raid/`、`src/presentation/`，行为由 `npm test` 和 `npm run qa` 验证，版本和证据见 [当前状态](../memory/STATUS.md)。

当前没有多人联机、服务端经济或完整角色雕塑/动作资产。后续扩展或更换引擎时先明确需要替代的契约，不覆盖旧档和参考工程后再补迁移方案。
