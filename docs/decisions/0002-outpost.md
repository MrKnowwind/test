# 0002 盐港整备、交易与战局界面

2026-11-25，基线 31b0acb。

- 新旧本地账户一次性领取 600 券，旧余额、已售数量和已入库物资继续有效。商店出售手枪、战术刀、七种背包、弹药和两种医疗品。买价固定，一盒弹药 12 发。
- 仓库按当前时间的五分钟区间和物品 ID 生成报价，在基准价的 80% 至 120% 之间取整。针剂每剩一格的基准价为 30 券。成交校验当前报价。
- 战前在仓库选包、武器和补给。配发手枪为 8 发弹匣和 15 发备弹，另有配发战术刀。仓库装备在实际进入出击时扣除，带出后归仓，死亡或放弃时随本局损失。创造练习退回该次从仓库领用的物资，练习期间获得的物资留在练习局。出生位置从三个经地图验证的固定候选位置随机抽取。
- 南侧卸货口有一件可直接获取的基础小包。各地储物柜保留概率背包。左侧任务栏由调查值班室文件盒、取得维修卡、呼叫货梯或进入有效撤离倒计时触发。
- 默认 Ctrl 或 C 切换下蹲，冲刺中触发滑铲。按住模式下，松开对应键可退出下蹲或滑铲。滑铲结束且净空允许时站立，滑铲中按空格可带动量起跳。B 临时检查弹药，左 Alt 静走。键位、蹲伏模式、鼠标灵敏度、总音量、音效、环境音、画质和小地图开关保存到本地。
