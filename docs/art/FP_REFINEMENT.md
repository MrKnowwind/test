# 第一人称轮廓与持握修订

更新于 2026-11-13。对应用户提供的本地 `1.mp4` 外观参考。本记录只描述手臂、手枪与小刀，不据视频画面推断参考资产的制作来源。

## 已实现

| 资产 | 本轮调整 | 源文件 |
| --- | --- | --- |
| 手枪 | 套筒宽度从 49 mm 收到 39 mm，握把高度从 118 mm 收到 94 mm；机匣用连续侧轮廓挤出，护圈有实际内孔；补独立后盖与小销钉，压低瞄具外形 | `src/presentation/viewmodelModels.ts` |
| 手套 | 用窄腕、展宽掌骨的连续掌面替换两层椭球；手指按长度收束，关节用局部曲面变化表达；拇指分别按持枪、支撑与空手姿态布置 | `src/presentation/handGeometry.ts`、`viewmodelModels.ts` |
| 袖子与腕部 | 前臂收束到手腕；衣褶集中在袖口附近；缝线跟随袖子半径；腕部壳体闭合并搭接，避免姿态变化时露出背景；织纹 UV 按周向 1.5、纵向 2 重复 | `src/presentation/viewmodelModels.ts` |
| 小刀 | 移除高对比绑带块，改为暗色握柄、浅槽、紧固件和尾帽；保留现有刀刃与攻击挂点 | `src/presentation/viewmodelModels.ts` |
| ADS 与换弹 | 瞄具高度与视图偏移同步为 32 mm；弹匣座位随新握把同步，支撑手跟随弹匣移动，进出动作仍由同一战斗进度控制 | `src/presentation/viewmodel.ts` |

模型是项目内参数曲面制作；材质由主会话维护的 `finishes.ts` 接入。手套、衣物、套筒使用对应材质，硬护片、聚合物机匣和刀柄明确使用独立 `polymer` 类型，防止皮革纹理铺在机匣上。所有运行时挂点名称保持不变，没有新增主武器资产。

## 已验证

- `node --test tests/art.test.mjs`：5 项通过，涵盖两种宽高比下 ADS 对齐、枪口火光、换弹接触与复位、感染体动作和机器人锁定。这里只将前三项作为本轮第一人称修改的行为依据。
- `npx tsc --noEmit`：通过。
- `node tests/art-browser.mjs test-results/fp-refine-final`：Chrome 157.0.8103.51 / RX 5700 XT / 1280×720，13 张截图，控制台、页面与资源错误均为 0。截图入口等待 AI 贴图完成加载后再重绘。
- 已人工审查腰射、ADS、换弹与小刀截图，修复首轮袖口白缝以及机匣误用皮革纹理的问题。

同机位修订前截图在 `test-results/fp-refine-before/`，最终截图在 `test-results/fp-refine-final/`。重点文件为 `01-pistol-hip.jpg`、`02-pistol-ads.jpg`、`04-pistol-reload.jpg` 和 `05-knife-ready.jpg`。测试机位、灯光与环境在 `tests/art-preview.ts`；本轮后期照明与材质由主会话共同更新，因此这些图用于整体修订对照，不是隔离单一几何变量的测量。

最终独立预览中的持枪帧总计约 98–99 次绘制、约 13 万渲染三角面，其中包含环境和阴影重复渲染。该数字不是资产独立面数，也不是整局帧率成绩。实机地图、长期运动和低配置性能由集成验收另记。

## 待验证与下一步

当前仍是参数化模型和手工姿态动画，缺少专门雕塑的手部解剖、独立 UV 烘焙和逐指蒙皮动画。截图确认了轮廓收束、材质分工与挂点行为，不能据此宣称已达到示例视频或 3A 角色资产精度。下一步应按实机地图中腰射、ADS、换弹的连续录像继续检查拇指接触和指部穿插，随后用雕塑与烘焙资产替换时保留现有挂点接口。
