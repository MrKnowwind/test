首片保留工业尺度，用变形货架、废弃工位、维修补丁和成片干湿差异表现撤离后的港区。高频磨损沿接缝、排水和使用位置分布。湿地、裸金属、涂层和橡胶各自保持合理的粗糙度与高光。远景压低饱和度，近战区留出清楚的局部照明与背景反差。敌人的发现与攻击预警由姿态、运动和声音共同传达，颜色和发光只加强已有信息。雨雾、枪口火光与命中特效采用短时、局部表现，保留准星与对手动作的辨识度。

## 人物与武器

- **第一人称手臂**。先做能读出腕部、掌指和袖口层次的一套双手与前臂。持枪手贴合握把，另一只手支撑武器并在换弹时准确接触弹匣。通过待机、转向、奔跑、瞄准、射击和换弹逐帧查指尖穿插、袖口断面和腕部变形。首片的完整骨骼人物制作预算优先给可见的生化敌人。
- **首把武器**。统一采用一款可明确辨认的虚构制式枪。外观以枪身比例、实做倒角、金属分件和不同材料的磨损为主。枪机、弹匣、扳机和瞄具按动作需求分件，螺钉、浅刻纹和多数表面微损伤可用烘焙法线与材质表达。通过中性光和地图灯光各拍一张近景，核对轮廓、材质差异和零件接缝。
- **瞄准与挂点**。武器输出枪口、前准星、后照门、握把和支撑手等稳定挂点。美术与工程共同确定资产单位、朝向和挂点命名。ADS（举枪瞄准）完成后，后照门、前准星和屏幕瞄准中心在基准姿态下对齐。FOV 变化、移动和后坐回正均要检查，贴近遮挡物时验证武器表现与实际命中一致。工程维护命中与近墙判定，资产挂点负责定位模型与特效。
- **动作与反馈**。交付持枪待机、移动与奔跑姿态、ADS 进出、开火回正和换弹。标注枪口特效、弹匣脱离与就位等动作帧，工程和数值确认生效时机及中断规则。可见枪机、弹匣动作和命中特效与游戏事件同步，重入动作时复查跳姿、穿插和特效重复。

| 地区 | 阶段 | 敌人造型与可读动作 |
| --- | --- | --- |
| 废弃装卸区 | 首片 | 生化敌人以不对称体态、旧工装残片和有机质增生建立轮廓。待机、追击、预备攻击、命中反应和死亡姿态各自易辨。预备攻击动作需要在遮挡边缘和低照度下也能读出方向与即将发生的位移。 |
| 地下实验室 | 首片 | 机械安保机采用硬壳、外露关节与传感器建立剪影，锁定、射击和失效用灯态及机械节奏区分。实验室用隔离门、管线和应急照明提示危险区域。 |

首种敌人交付完整骨骼和蒙皮、关键姿态及全套首片动作。用灰材质、地图背光和常用交战距离检查前后侧轮廓，确认脚底接地、受击时的关节形变、倒地时的穿插，以及外观与命中区域的吻合。若设计启用弱点，在轮廓或结构上先给出线索，再以材质对比辅助。

## 资产交接与性能

- 每项资产记录稳定 ID、负责人、来源与许可、可编辑源文件、运行时导出物、挂点、材质和动画清单、尺寸及对应验收证据。命名建议使用小写英文和下划线，例如 `weapon_carbine_a_fp`、`enemy_infected_a`、`prop_cargo_door_a`。可编辑源文件和运行时资源分开管理，合并之前核对来源与再分发许可。
- 若采用 Three.js，模型交付优先用 glTF/GLB。在导入场景实查单位、朝向、枢轴、挂点、材质色彩空间、蒙皮和动画。首人称武器与手臂使用稳定的近景版本。敌人及重复场景资产按屏幕占比和实测决定 LOD，优先保证轮廓和动作一致。环境模块优先共用材质，按实测决定实例化、贴图压缩和反射裁剪。
- 先固定设备、浏览器版本、分辨率、画质档和测试动线，在空场景、典型战斗和高负载同屏分别记录帧时间、可见三角面、draw calls 与纹理占用。再为第一人称资产、敌人与环境确定预算。旧 Demo 的单机固定视角成绩仅供对照，新战斗切片的预算和达标状态以新测量记录为准。

## 首片验收与维护

1. 截图覆盖出生点、交战路线、搜刮点、撤离点、持枪近景、ADS 和敌人正侧面。先拍中性光或调试视图，再拍实机地图，记录画质和机位。
2. 录制从奔跑到 ADS、开火、换弹的连续操作，同时用近墙、亮暗交界和多种宽高比复验对齐与裁切。用固定靶将机瞄画面与命中结果放在同一份验收记录中。
3. 在低画质与典型交战距离录制敌人发现、预备攻击、实际攻击和受击退场。设计确认动作读得懂，工程确认触发点与命中区域，数值确认动作时长和反馈窗口。
4. 每次资产修改后更新该项记录的状态、验证条件与截图或视频路径。需要跨职责确认的改动包括瞄具位置、武器事件帧、敌人轮廓与碰撞、关卡照明和撤离指引。
